A professional, modern, and fully responsive website for **Dr. Ali Ahmed A**, an experienced Orthopedic Surgeon based in Algeria. The platform is designed to provide patients with an intuitive digital experience, allowing them to easily explore medical specialties, learn about the doctor's expertise, and book appointments online.

🌐 **Live Website / Site Web :** [https://dr-ali-ahmed.vercel.app/](https://dr-ali-ahmed.vercel.app/)

## ✨ Features / Fonctionnalités

- **Modern & Responsive Design:** Built with a user-centric approach, ensuring a seamless experience across all devices (desktop, tablet, and mobile).
- **Specialties Showcase (Spécialités):** Detailed information about orthopedic services including knee surgery, hip replacement, traumatology, arthroscopy, spine care, and sports medicine.
- **Online Appointment Booking (Rendez-vous):** A dedicated and easy-to-use form for patients to schedule consultations securely.
- **Patient Testimonials & Statistics:** Highlights of the doctor's experience (15+ years) and success rates to build trust.
- **Contact & Location Info:** Integrated map and clear communication channels.

## 🛠️ Technology Stack / Technologies

- **Frontend:** Next.js / React
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
